# AI Collaboration Guidelines for Full-Stack Application

## Project Overview
This is a comprehensive full-stack web application with React frontend, Express backend, and PostgreSQL database.

## Architecture
- Backend: Express.js + TypeScript + PostgreSQL
- Frontend: React + TypeScript + Vite
- DevOps: Docker + GitHub Actions
- Testing: Jest + React Testing Library

## AI Agent Rules
1. Preserve existing functionality unless explicitly asked to change
2. Follow established patterns and naming conventions
3. Add comprehensive tests for new functionality
4. Update documentation when making changes
5. Use TypeScript strictly throughout
6. Follow RESTful API conventions
7. Implement proper error handling and validation

## Development Workflow
1. Create feature branches from main
2. Run tests and linting before commits
3. Submit PRs with detailed descriptions
4. Deploy after code review

## Key Commands
- Setup: ./scripts/setup/install.sh
- Development: npm run dev
- Testing: npm test
- Linting: npm run lint

## Contact
Escalate complex architectural decisions to senior development team.
